- Hosting: Netlify (netlify.toml, @netlify/vite-plugin-tanstack-start). Every push to `main` redeploys the live app, so keep `main` in a working state (`npm run build` and `npm test` must pass).
- Database and auth: Supabase. The full schema lives in supabase/setup.sql; when you change the schema, add the SQL to that file and tell the owner to run the new part in the Supabase SQL Editor.
- Business rules (prices, follow-up dates, streak, ranks, stages) live in src/lib/business.ts with tests beside it; keep UI free of these calculations.
- Signed-in pages live under src/routes/_authenticated/ (client-only gate); data is read directly with the browser client and protected by row-level security.
- The first account created automatically gets the admin role (signup trigger); shared content tables are admin-write, everyone-read.
- The app's users are French-speaking: all UI text, messages and the README stay in French.
